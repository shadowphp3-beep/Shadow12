# SHADOW_APPS — تطبيقان لموقع Shadow (الإصدار المبني على الموقع v38)

> **حالة التسليم بصراحة:** هذه الحزمة تحتوي على **كود مصدر كامل ومنظّم للتطبيقين مع إعدادات البناء**، لكنها **لا تحتوي** على ملفي `ShadowAdmin.exe` و`ShadowStore.apk` جاهزين. بيئة التطوير التي أُعدّت فيها لا تملك إنترنت ولا Android SDK ولا Windows، فلم يكن ممكنًا بناء الملفين أو اختبارهما فعليًا. بناؤهما يتم بأمر واحد لكل تطبيق على جهازك (التفاصيل في `Documentation/INSTALLATION_AR.md`). التقرير الكامل بما اختُبر وما لم يُختبر: `Documentation/TEST_REPORT_AR.md`.

## ما الموجود

| المجلد | المحتوى |
|---|---|
| `Source_Code/Admin` | تطبيق **Shadow Admin** لويندوز (Electron): يفتح لوحة تحكم موقعك داخل نافذة محصّنة، مع شاشة إعداد الخادم وشاشة انقطاع الاتصال. |
| `Source_Code/Android` | تطبيق **Shadow Store** للأندرويد (Kotlin + WebView): يعرض الواجهة العامة للعملاء ولا يفتح أي مسار إدارة. |
| `Documentation` | التثبيت والبناء، شرح الربط والمزامنة، وتقرير الاختبار. |

## ما اكتُشف في الموقع (ويحدد شكل التطبيقين)

- الموقع PHP يعمل بقاعدة MySQL (أو SQLite احتياطيًا)، والصفحات تُرسم من الخادم، ولوحة الإدارة نماذج HTML محمية بجلسة وCSRF **وليس فيها JSON API للإدارة**. لذلك تطبيق الأدمن يغلّف اللوحة الحالية ولا يعيد كتابتها (لا يضيع أي وظيفة ولا يتغير شيء في الصلاحيات).
- الموقع **ليس متجر منتجات وطلبات شراء**: هو موقع خدمات صيانة/فك أقفال هواتف (خدمات، عروض، معرض أعمال، حجوزات، طلبات فحص، رسائل، حسابات عملاء، محاسبة). لذا تطبيق العملاء يعرض هذه الأقسام الموجودة فعلًا ولا يخترع منتجات أو سلّة شراء.
- **لا يوجد WebSocket.** الموجود فعلًا مزامنة بالاستعلام الدوري: `?r=api/live` ورقم إصدار الموقع `site_version` الذي يرتفع عند أي حفظ من لوحة الإدارة، وملف `assets/js/live.js` يحدّث الصفحة تلقائيًا. التطبيقان يعتمدان على هذه الآلية نفسها، فهي **شبه لحظية بالاستعلام الدوري وليست دفعًا فوريًا**.
- **لم أغيّر أي ملف في الموقع**، ولا حاجة لتعديل على الخادم، باستثناء خطوة تشغيلية واحدة لربط حساب الأدمن بالتطبيق (انظر `CONNECTION_AR.md`).
